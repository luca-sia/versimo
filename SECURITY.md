# Security policy

## Reporting a vulnerability

Please report security issues by email to **security@lucasia.ai**. Do not open a public issue for them.

Include what you found, how to reproduce it, and which version you used. We will reply within five working days and keep you informed until it is fixed.

## Supported versions

Only the latest release gets security fixes.

## Scope

This package has no runtime dependencies and makes no network calls except the ones you configure through a URL source. Records you load are data you trust, so serve them over HTTPS from a place you control.
